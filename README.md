# SymNet: Symbolic Multi-Layer Perceptron based DSL Compiler for Group-Theoretic Boolean Expressions

[![C++ Standard](https://img.shields.io/badge/C%2B%2B-17%2F20-blue.svg)](https://en.cppreference.com/w/cpp/17)
[![Build System](https://img.shields.io/badge/CMake-3.18%2B-brightgreen.svg)](https://cmake.org/)
[![Python Extension](https://img.shields.io/badge/Pybind11-v2.13%2B-orange.svg)](https://github.com/pybind/pybind11)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![DOI](https://zenodo.org/badge/1453389569.svg)](https://doi.org/10.5281/zenodo.24123292)

**SymNet** is a high-performance, domain-specific compiler and native C++ 17 SIMD runtime engine. It translates symbolic group-theoretic expressions, continuous Lie manifold operators ($SO(2)$ phasors), and non-linear set partitions into constant-time ($O(1)$), zero-branch linear tensor graphs.

By replacing dynamic evaluation loops over sequence word lengths $L$ with static constant folding and feature space lifting, SymNet accelerates symbolic membership queries from **$145\ \mu\text{s}$ down to $9\text{ ns}$**.


## Key Architectural Features

1. **Algebraic Constant Folding ($O(1)$ Runtime Complexity)**  
   Given a word $w = g_1 \cdot g_2 \cdots g_L$, the compiler pre-multiplies generator sequence matrices at compile time:
   $$W_{\text{compiled}} = F_1 \times F_2 \times \cdots \times F_L \in \mathbb{R}^{k \times k}$$
   Evaluating word membership requires **exactly one matrix pass**, independent of word length $L$.

2. **Automated Non-Linear Feature Lift Synthesis**  
   Integrates a Novikoff perceptron cycle detector to automatically discover non-linear dimensional coordinates ($\Phi$) for non-separable group boundaries (e.g., discovering $z = \vert{}x - y\vert{}$ for XOR partitions, or $z = m_{00} \cdot m_{11}$ for Klein 4 / $D_4$ subgroup cosets).

3. **Direct SIMD Tensor Execution**  
   Element-mode transformations act directly on state matrices $X \in \mathbb{R}^{k \times k}$ ($X \leftarrow W X$) rather than expanding full Kronecker products $\text{kron}(W, I)$, lowering matrix complexity from $\mathcal{O}(k^4)$ to $\mathcal{O}(k^3)$. Uses unrolled, 64-byte aligned (`alignas(64)`) stack buffers for $k \in \{2, 3, 4\}$ with four-accumulator dot products for autovectorization.


## Benchmark

D4 word `(r*s)^(L/2)` classified against the subgroup `{e, s}`, one decision per pass
(x86_64, `-O3 -march=native`; absolute numbers vary by machine and run):

| word length L | folded (this engine) | per-factor O(L k^3) | dense Kronecker O(L k^4) |
|---:|---:|---:|---:|
| 3    | 9 ns | 22 ns   | 61 ns    |
| 128  | 9 ns | 790 ns  | 2.2 us   |
| 8192 | 9 ns | 53 us   | **145 us** |

The folded pass stays at about 9 ns from L = 3 to L = 8192 (145 us -> 9 ns at L = 8192).
Reproduce with `build/tests/unit_tests`.

## Layout

```
include/symnet/   header-only engine: Common, MatrixEngine, AST, Lexer, Parser, Compiler,
                  Runtime, Interpreter, WordEval, Examples
src/              main.cpp (symnet_cli), bindings.cpp (pybind11 module `symnet_native`)
tests/            cpp/test_engine.cpp (unit tests + benchmark), python/test_bindings.py
single_header/    symnet_native_single.cpp, generated by scripts/amalgamate.py
```

## Build and test

Requires CMake >= 3.18 and a C++17 compiler. The Python module additionally needs Python >= 3.8
and pybind11 (found automatically if `pip install pybind11` was run, otherwise fetched).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
```

Useful options: `-DSYMNET_NATIVE_ARCH=OFF` (portable binaries), `-DSYMNET_STRICT_FP=ON`
(`-ffp-contract=off`, bit-identical to numpy), `-DSYMNET_BUILD_PYTHON=OFF`,
`-DSYMNET_FETCH_PYBIND11=OFF`.

## Usage

**CLI**

```bash
./build/symnet_cli                 # built-in Phase 1 + Phase 2 demonstrations
./build/symnet_cli -v              # full transcript with per-layer traces
./build/symnet_cli program.sym     # your own DSL file
```

**C++** (header-only; the target carries the include path and C++17)

```cmake
target_link_libraries(my_app PRIVATE SymNet::native_cpp)
```

```cpp
#include <symnet/Interpreter.hpp>
symnet::SymNetInterpreter interp(10.0, &std::cout);
symnet::Report r = interp.run(dsl_text);
```

**Python**

```bash
PYTHONPATH=build/python python3 -c "
import symnet_native as sn
r = [0,-1,1,0]; s = [-1,0,0,1]
print(sn.eval_word_compiled(2, r+s+r, [0,0,0,1], -0.5))   # True: r*s*r == s
cw = sn.CompiledWord(2, (r+s)*4096)                       # fold once ...
print(cw.decide([0,0,0,1], -0.5))                         # ... decide with 0 matrix passes"
```

`eval_word_compiled` folds on every call; `CompiledWord` folds once and then decides in O(1).
Install with `cmake --install build --prefix ~/.local`.

## Notes

- `-march=native` applies to in-tree targets only; the installed `SymNet::native_cpp` target
  does not impose it on downstream projects.
- After editing a header or `src/main.cpp`, regenerate the single file with
  `python3 scripts/amalgamate.py`; CTest builds and runs it so a stale copy is caught.
